Middle-Click on the Pick button to select previous color slot before picking.

Right-Click on the Random button to randomize all color slots.
Middle-Click on the Random button to select a random color slot.

Right-Click on the Empty button to empty all color slots.
Right-Click on the Invert button to invert all color slots.
